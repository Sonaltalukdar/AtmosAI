# AtmosAI 🌤️

AtmosAI — AI-powered weather & air quality assistant (frontend)

AI-powered weather assistant with real-time weather updates, air quality index (AQI), humidity, wind speed, and an interactive AI chat interface.

## Features
- 🌡️ Live weather stats (temperature, humidity, wind, pressure, UV index, visibility)
- 💨 Air Quality Index (AQI) tracker
- 💬 AI chat assistant for weather queries
- 🎨 Modern glassmorphism UI with smooth animations

## Tech Stack
- React
- Tailwind CSS
- Lucide Icons

🚧 Frontend in progress — backend/API integration coming soon.
